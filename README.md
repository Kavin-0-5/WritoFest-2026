## About the Project

**WritoFest 2026** is an event website created to bring the event experience online. It helps visitors explore the activities, view event information and timeline, access the brochure, and find the registration form in one place.

The event is presented by **ScriptInk - the Technical and Literary Club of Siddaganga Institute of Technology (SIT), Tumkur**.

## Event Details

- **Date:** 3 November 2026
- **Venue:** Media Centre
- **Organiser:** Team ScriptInk, SIT Tumkur

## Featured Events

- **Ink Your Script** - Write poems and stories inspired by images and imagination.
- **Open Mic** - Share your voice, ideas, and talent.
- **Pop-Up Quiz** - Test your knowledge and quick thinking.

## Website Features

- Responsive layout designed for desktop and mobile screens
- Event sections and timeline
- Registration form with input validation
- Event brochure access
- FAQ interactions and image gallery
- Links to ScriptInk's social media
- Consistent black, white, brown, and gold visual theme

## My Development Work

The project involved building and refining the event website, with attention to both presentation and usability:

- Developed the website using HTML, CSS, and JavaScript.
- Worked on responsive layouts and mobile-specific visual refinements.
- Implemented client-side registration field validation.
- Refined interface elements such as the timeline, gallery, FAQ section, and navigation.
- Prepared the repository structure for a straightforward static-site deployment.



## Tech Stack

- **HTML** - page structure
- **CSS** - styling and responsive layouts

- **Vercel** - website deployment

## Run Locally

This is a standalone HTML project, so no package installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Kavin-0-5/WritoFest-2026.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
