# WritoFest 2026 ✨

A celebration of creativity, words, voices, and ideas, presented by **ScriptInk — the Technical and Literary Club of SIT Tumkur**.

🌐 **Live Website:** https://writo-fest-2026-7grs.vercel.app/  
📸 **Instagram:** https://www.instagram.com/scriptink_official/

## About

WritoFest is a campus event that brings together students who enjoy writing, performing, and challenging their knowledge. The website serves as the event's online hub, helping visitors explore the event and find registration information.

## Events

- **Ink Your Script** — Create poems and stories inspired by images and your imagination.
- **Open Mic** — Share your voice, ideas, and talent on stage.
- **Pop-Up Quiz** — Put your knowledge and quick thinking to the test.

## Event Details

- **Date:** 3 November 2026
- **Venue:** Media Centre
- **Organised by:** Team ScriptInk, SIT Tumkur

## Website Highlights

- Responsive design for desktop and mobile devices
- Event information and timeline
- Registration form with input validation
- Brochure access
- Links to ScriptInk's social media

## Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Kavin-0-5/WritoFest-2026.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No build step is required for the standalone HTML page.
